# 📹 Apna Video Call

**Apna Video Call** is a real-time video calling and chat application that allows users to connect with each other through **live video calls and instant messaging**, similar to platforms like Google Meet.

🔗 **Repository:** [https://github.com/mishrarakesh-1902/Apna-Video-Call](https://github.com/mishrarakesh-1902/Apna-Video-Call)


---

## 📌 About the Project

Apna Video Call is built to enable seamless **peer-to-peer communication**, where users can:

* Talk face-to-face using video calls
* Chat simultaneously during the call
* Experience smooth and real-time interaction

This project focuses on real-time communication concepts and modern web technologies.

---

## ✨ Features

* 🎥 Real-time video calling
* 💬 Live chat during video calls
* 🔊 Audio & video streaming
* 🌐 Peer-to-peer connection
* 📱 Responsive UI (works on desktop & mobile)
* 🚀 Fast and interactive experience

## ⚙️ Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mishrarakesh-1902/Apna-Video-Call.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Apna-Video-Call
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the server:

   ```bash
   npm start
   ```

5. Open your browser and visit:

   ```
   http://localhost:3000
   ```

---

## 🧠 How It Works

* WebRTC handles direct video/audio streaming between users
* Socket connections manage:

  * User signaling
  * Real-time chat messages
* Backend server coordinates communication between peers
